# Исходные данные — только для чтения

`data_EFVB_out/` и `data_ECVB_out/` содержат по 30000 пар `vp_00000.txt`/`vs_00000.txt` … `vp_29999.txt`/`vs_29999.txt`. Всего 120000 исходных полей. Их содержимое при реорганизации не менялось и не перемещалось.

Один файл — текстовый массив 70×70 скоростей в м/с. Первая строка соответствует верхней границе, столбцы — слева направо, свойства заданы в ячейках 10×10 м. Плотность предполагается постоянной 1000 кг/м³. Подробная постановка — [vasily_message.txt](vasily_message.txt).

Оригинальные ZIP `data_EFVB_out.zip` и `data_ECVB_out.zip` можно разместить здесь вместо распакованных каталогов; локально их наличие не предполагается. Конвертер не записывает в `src/` и при наличии ZIP отдаёт ему приоритет.

Данные исключены из нового Git. После клонирования их нужно восстановить из отдельной копии. Контрольные суммы и рецепт проверки сохранены в [статистике](../data/dev_1_1_preprocessing/dataset_statistics.json). Адрес внешнего хранилища пользователем ещё не назначен.
