# Расчётные данные

`dev_1_1_preprocessing/` содержит статистику, бинарный manifest и восстанавливаемые NPZ-блоки. `dev_1_2_smoothing/` содержит выбранные модели, геометрию, расчётные серии и метрики.

Git сохраняет компактные JSON и Markdown. Массивы NPZ/NPY, сетки, native-файлы и другие тяжёлые продукты остаются локальными. Даже три малых исходных fixture NPZ исключены по единой политике нового проекта; их пути и SHA256 включены в карту переноса.

Локально доступны выбранные модели №12404/№65, фиксированная Q2-геометрия и полные массивы CU-повтора №12404. Основные 60 бинарных блоков, полные массивы старой Windows-серии и модельные сетки №65 отсутствовали в переносимой папке; перенос не объявляет их восстановленными.

Исторические JSON не редактировались: абсолютные Windows/Linux-пути внутри них обозначают происхождение опыта. Актуальное расположение задаёт [file_map.json](../docs/migration/file_map.json). Старые Python-источники сохранены как текстовые снимки; native-файл CU сохранён локально в `dev_1_2_smoothing/provenance_runtime/` для проверки SHA256, не для импорта или исполнения.
