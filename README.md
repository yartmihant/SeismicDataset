## Воспроизведение

Редактируемый источник каждой главы — одноимённый файл Python. Команда конвертирует его в ноутбук, проверяет обратное преобразование и выполняет отчётные ячейки на сохранённых результатах.

```bash
.venv/bin/python -m scripts.build_notebooks --execute
```

В окружении с закрытыми сокетами флаг `--in-process` выполняет те же ячейки через IPython внутри процесса сборки.

[Внешние публикации](ref/README.md) · [Среда](docs/ENVIRONMENT.md) · [Исходные поля](src/README.md) · [Построение ECVB](docs/dev_1_6_fidesys_mesh.md) · [Параметры и история запуска EFVB](docs/dev_1_6_p64s_production_spec.txt)

Номера каталогов в data, img и scripts обозначают исходный этап эксперимента. Реферат каждой новой главы перечисляет материалы из всех использованных этапов. Снимки серверных запусков датированы.
