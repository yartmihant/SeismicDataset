# lin_elast_2d_seismic_newmark_kim_p5_cu — внешний контракт

Экспериментальный CUDA-решатель для сеток со штатным `ALine(order=5)` служит эталоном специализации на фиксированный порядок. Модуль входит в сборку `SEMGPU2_BUILD_CUDA=1` и доступен под собственным именем.

```python
from semgpu2.solvers import lin_elast_2d_seismic_newmark_kim_p5_cu
```

Физика, поля состояния FP64, интегрирование Ньюмарка–Кима, SAVE, синхронный и асинхронный запуск и приёмники соответствуют [контракту штатного сейсмического решателя](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_CU_EXTERNAL2.md).

## Входная сетка

`compile(n_count, pets, pq_spaces)` использует число глобальных узлов и топологию пространств. Аргумент `pets` сохраняется для совместимости с SolverAPI и игнорируется. Константы W, V и G задаются при сборке.

MAIN содержит два фактора с ID 0 и 36 локальных P/Q-позиций на элемент. BOUNDARY содержит один фактор с ID 0 и шесть позиций на грань. Решатель проверяет ранги, ширины, смещения и индексы связности при `compile()`. Вызывающий код обеспечивает штатное расположение и нумерацию узлов ALine p5. Решатель принимает сетку той же ширины с иной нумерацией, но применит к ней встроенные операторы в штатном порядке.

Первый фактор меняется быстрее второго. Локальная позиция MAIN равна \(j=j_0+6j_1\), где \(0\le j_0,j_1<6\). На границе она равна \(j=j_0\).

Адресная регрессия сравнивает состояние при SAVE, продолжение и CFL-спектр со штатным решателем на неоднородном материале и выбранных гранях ABC. Отдельно проверяются пустой и изменённый внешний PET и отказ на сетке p4. [Тест p5](../../tests/tests_lin_elast_2d/seismic_newmark_kim/test_reg_seismic_p5.py).

Получение таблиц и устройство ядер описаны во [внутренней карточке](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_P5_CU_INTERNAL2.md).
