# lin_elast_2d_seismic_newmark_kim_p5_cu — внутреннее устройство

Специализация задаёт размер фактора и его операторы во время компиляции. Схема шага и математическая постановка совпадают со [штатным сейсмическим решателем](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_CU_INTERNAL2.md).

## Таблицы ALine p5

В константной памяти CUDA объект `factor` хранит 6 весов W, 36 значений базиса V и 36 производных G. Матрицы записаны построчно в порядке `[q, p]`. При коллокации действие V выполняется выбором узлового значения. Градиент использует G, сопряжённая дивергенция использует транспонированную G, а при вычислении геометрической меры используются веса W. [Таблицы и свёртки](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p5_cu/backend/operators/pet.cuh).

В сборке SM86 ядра геометрии и отклика содержат по локальной копии `factor`. В секции `.nv.constant3` каждого из двух CUDA-модулей все 624 байта побитно совпали с таблицами штатного ALine p5.

## Адресация

Ось x CUDA-блока задаёт локальную позицию, ось y — элемент или грань. При лимите 512 потоков блок MAIN имеет размеры `(36, 14)`, блок BOUNDARY — `(6, 85)`. В неполном последнем блоке все потоки проходят барьеры. Циклы одномерных свёрток имеют фиксированную длину шесть. Индексы глобальной связности и полей имеют тип `int64`, локальные индексы — `int`.

## Специализация на другой порядок

1. Задать `PET_N = order + 1` и проверить, что элемент MAIN целиком помещается в блок. Его ширина равна \((p+1)^2\), ширина грани — \(p+1\). [Размер фактора и предел блока](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p5_cu/backend/constants.hpp).
2. Получить таблицы штатного ALine выбранного порядка без сжатия по симметрии. Код ниже выдаёт списки шестнадцатеричных FP64-литералов в порядке и раскладке полей `FactorTables`. Для p5 они побитно совпадают с таблицами, выдаваемыми `rectangle_quad_fast(...).build_pets_data()`.
3. Поместить таблицы в `factor`, дать варианту отдельный solver ID и добавить его в сборку через `add_seismic_solver`. Проверить коллокацию нового фактора и сравнить результат со штатным решателем на сетке нужного порядка. [Цели сборки](../../CMakeLists.txt), [пример проверки p5](../../tests/tests_lin_elast_2d/seismic_newmark_kim/test_reg_seismic_p5.py).

```python
from semgpu2.model import SGPETALineModel

order = 5
local = SGPETALineModel("line", order=order).build_data(use_symmetry=False)
tables = (local.weights, local.values, local.grads[:, :, 0])
w, v, g = [[float(value).hex() for value in table.flat] for table in tables]
```
