# Сейсмический p6 для семи независимых источников

`lin_elast_2d_seismic_newmark_kim_p6_7s_cu` интегрирует семь независимых задач плоской деформации на одной сетке в FP64. Для всех опытов общие координаты, связность, упругие свойства, профиль PML и внутренняя временная сетка. Каждый опыт имеет собственные перемещения, скорости, ускорения и историю PML. Семь источников входят в контракт решателя. Модуль входит в CUDA-сборку semgpu2 и реализует штатный [SolverAPI](../SOLVER_API2.md).

## Сетка и физика

В `SGMeshModel.strata` задают только MAIN (1) с сигнатурой `(2, 2, 2)`. Каждый элемент имеет два фактора ALine p6 и 49 локальных P/Q-позиций. Узлы N (0) общие для всех опытов. Объёмная геометрия может быть криволинейной, а материал — неоднородным по Q. Свободная поверхность получается из естественного условия слабой формы при нулевом поверхностном усилии.

- `MATERIAL_ISO_PLANE_STRAIN` (11000) задаёт `rho, E, nu` на MAIN. Материал покрывает каждый элемент, включая слой.
- `PML` (31100) задаёт `dx, dy` по физическим осям на выбранных MAIN-элементах. На пересечении носителей профили складываются покомпонентно. После выбора шага решатель готовит упругий материал слоя с коэффициентами рекурсии. [Декартов PML](CARTESIAN_PML2.md)

При переходе с прежнего `p6_7s` удалите вызов `model.add_physics(source)`. Если в модели остался активный объект силы 20200, `prepare()` выдаст `SGPrepareError` до копирования таблицы из входных данных решателя.

## Встроенный источник

Геометрия верхней границы и её нумерация принадлежат контракту решателя. Верхний ряд при `y = 0` занимает первые 1261 узел с номерами `0…1260` в порядке возрастания x от −350 до 1750 м. Он содержит 210 отрезков шириной 10 м с узлами Гаусса — Лобатто порядка 6. Семь источников действуют вниз в узлах `315, 420, 525, 630, 735, 840, 945` для опытов `s = 0…6`. Их координаты x равны 175, 350, 525, 700, 875, 1050 и 1225 м. `compile()` требует наличия полного диапазона этих номеров. `mesh()` проверяет координаты всего верхнего ряда с абсолютным допуском \(10^{-9}\) м по каждой оси. Число N и геометрия ниже верхней границы могут отличаться от эталона при сохранении этой верхней границы и проверяемой MAIN-топологии.

Старая сетка, где верхний ряд был в конце нумерации, требует конверсии. `with_leading_nodes` переносит указанные старые N-номера в начало, сохраняет относительный порядок остальных узлов и возвращает отображение старого номера в новый. Он перестраивает `nodes_coords`, `nodes_tags` и все `p_nodes` страт, поэтому локальная связность MAIN продолжает указывать на координату того же физического узла. Индексы элементов и Q-позиций сохраняются.

```python
import numpy as np
from semgpu2.tools.mesh.numbering import with_leading_nodes

mesh, old_to_new = with_leading_nodes(old_mesh, top_ids)
receiver_node_ids = old_to_new[old_receiver_node_ids]

# Для restart переставляют N-столбцы сохранённого состояния.
migrated_solution = np.empty_like(saved_solution)
migrated_solution[:, old_to_new] = saved_solution
```

`top_ids` является одномерным `int64`-массивом номеров старого верхнего ряда в порядке слева направо. Для продолжения из `SAVE` переносят все N-поля этим же отображением. PML-история сохраняет порядок, так как конверсия не меняет элементы, локальные Q-позиции и `pml_entity_ids`.

После построения фактической временной сетки `prepare()` вычисляет FP64-массив значений Рикера для каждого внутреннего шага. Его параметры принадлежат `source_profile` в нативных константах: `frequency_hz = 30`, `peak_time = 1.5 / frequency_hz` и `amplitude_y = -1` Н/м. Для абсолютного времени `t` решатель использует

\[
F_y(t)=-\left(1-2q^2\right)\exp(-q^2),\qquad q=\pi f_0(t-t_0).
\]

На каждом шаге одно значение применяется ко всем семи опытам. В каждом опыте оно добавляется в вертикальный отклик одного узла, заданного функцией `source_profile::node(shot)`. Для изменения частоты, времени пика, амплитуды или адресов редактируют константы и пересобирают CUDA-цель `semgpu2_seismic_p6_7s_cu_native`. [Параметры источника](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p6_7s_cu/backend/constants.hpp)

Такт 0 публикует начальное состояние без приложения силы. При ненулевом `t_begin`, включая продолжение после `SAVE`, массив строится на абсолютных временах расчёта. Изменение шага, границ времени или повторный `prepare()` создаёт новый массив для новой временной сетки. При `max_steps` решатель хранит лишь достижимый префикс массива.

```python
from semgpu2.model import SGModel
from semgpu2.solvers import lin_elast_2d_seismic_newmark_kim_p6_7s_cu as p6_7s

solver = p6_7s.SGSolver(p6_7s.SGSolverConfig(
    t_begin=0., t_end=1., tact_dt=0.001, cfl_safety=0.8, kim_beta=1/27, kim_gamma=0.5,
))
model = SGModel(mesh, solver)
model.add_physics(material)
model.add_physics(pml)
model.add_receiver(surface_receiver)
model.prepare()
result = model.run(sync=True)
```

## Приёмники и сохранение

Приёмник N или MAIN принимает коды `SGReceiverComponentEnum`. Для первого опыта это `VX, VY`, для последующих — `VX_S2, VY_S2` … `VX_S7, VY_S7`. При порядке компонент из `list(SGReceiverComponentEnum)` полученный кадр можно читать как `frame.reshape(7, 2, frame_size)`. Поверхностный приёмник задаётся обычным списком узлов поверхности на единственной сетке.

`solutions[0]` имеет форму `(42, N)`. Внутри шестистрочного блока опыта идут `UX, UY, VX, VY, AX, AY`. У `SGNSolutionComponentEnum` те же суффиксы опытов. Внутреннему узловому отклику соответствуют 14 компонент `SGNResponseComponentEnum`. Код наблюдения выбирают из перечисления приёмника. Например, `SGReceiverComponentEnum.VY_S7` имеет код 41, а `SGNSolutionComponentEnum.VY_S7` указывает строку 39.

`SAVE` сохраняет все 42 строки узлового решения и `pml_history` формы `(28, 49 * len(pml_entity_ids))`. Четыре строки каждого опыта соответствуют производным в порядке x/ux, x/uy, y/ux, y/uy. Столбцы упорядочены сначала по `pml_entity_ids`, затем по локальной Q-позиции. Для продолжения готовят экземпляр с тем же носителем PML и начальным временем сохранённого состояния, проверяют порядок элементов и копируют оба массива после `prepare()`.

В режиме CFL спектральная проба вычисляет упругую жёсткость на одной сетке с общей узловой массой. `lambda_max_damping` равен нулю. Слой использует фактический шаг после округления временной сетки. Повторный `prepare()` пересчитывает коэффициенты и обнуляет историю. [Внутреннее устройство](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_P6_7S_CU_INTERNAL2.md)
