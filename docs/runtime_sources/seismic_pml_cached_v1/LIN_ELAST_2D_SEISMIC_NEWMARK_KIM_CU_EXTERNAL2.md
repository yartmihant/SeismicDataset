# lin_elast_2d_seismic_newmark_kim_cu — внешний контракт

Решатель интегрирует двумерные уравнения изотропной упругости в плоской деформации явной схемой Ньюмарка–Кима в FP64 на CUDA. Импорт класса и конфигурации выполняется из `semgpu2.solvers.lin_elast_2d_seismic_newmark_kim_cu`. Сборка пакета с `SEMGPU2_BUILD_CUDA=1` включает собственное расширение этого решателя.

## Стадии и сетка

`compile(n_count, pets, pq_spaces)` принимает один коллоцированный одномерный PET. При \(P_1=Q_1=n\) MAIN содержит два фактора, BOUNDARY один. Каждый элемент занимает до 512 локальных Q-позиций. Отображения в глобальные узлы произвольны. Проверка единственной симметрии, орбит и тождественных V и T с абсолютным допуском \(10^{-12}\), а также использование заданных W и G следуют [структурному контракту tenzor, §3](LIN_ELAST_2D_TENZOR_NEWMARK_KIM_CU_EXTERNAL2.md#3-пространства-и-структура). MAIN непуст. BOUNDARY может отсутствовать.

`mesh(n_coords)` читает координаты формы (2, N), строит меры, обратные якобианы и единичные нормали. `prepare()` проверяет физику, собирает массу и выбирает параметры временной сетки. При повторной подготовке материализованные поля строятся заново.

## Активная физика

| Код | Тип | Пространство | Компоненты |
| ---: | --- | --- | --- |
| 11000 | MATERIAL_ISO_PLANE_STRAIN | MAIN | density, young_modulus, poisson_ratio |
| 20200 | N_FORCE_DYNAMIC | N | fx, fy |
| 30001 | N_MASS_DAMPING_STATIC | N | coefficient |
| 31100 | PML | MAIN | dx, dy |
| 32000 | ABC | BOUNDARY | normal_impedance, tangential_impedance |

Каждый элемент MAIN входит ровно в один материальный домен. По другую сторону общего узла элемент получает собственные значения материала. Остальные поля допускают частичные носители и несколько PhysicsId с суммированием. Узловая сила измеряется как сила и интерполируется в момент конца внутреннего шага. Вне заданного временного интервала её значение нулевое. Ненагруженная свободная грань даёт нулевую тягу. На стыке граней ABC суммируются обе граничные формы. Активный неизвестный код, неверный носитель, пересечение или пробел материальных доменов дают `SGPrepareError(PHYSICS_FAILURE)`.

## Поля и продолжение

В таблице указаны строки в порядке хранения. У пустого поля ноль строк, число столбцов определяется пространством N, MAIN или BOUNDARY. Все поля имеют dtype float64.

| Семейство | N | MAIN | BOUNDARY |
| --- | --- | --- | --- |
| solutions | UX, UY, VX, VY, AX, AY | пусто | пусто |
| responses (внутреннее) | FORCE_X, FORCE_Y | пусто | пусто |
| geometries | X, Y, SIZE | SIZE, DIFGEOMETRY_XX, DIFGEOMETRY_XY, DIFGEOMETRY_YX, DIFGEOMETRY_YY | SIZE, NORMAL_X, NORMAL_Y |
| materials | MASS | DENSITY, LAMBDA, MU | пусто |

`solutions`, `geometries` и `materials` предоставляют канонические host-поля через `SGStateArray`. Следующая сессия захватывает записанные контроллером значения, включая MASS, LAMBDA и MU. Каждая строка самостоятельна. После доверенной записи контроллер отвечает за согласованность полей и временного шага. `SAVE` возвращает шесть строк решения. При наличии PML та же команда сохраняет историю слоя. Для продолжения в новом экземпляре с теми же сеткой, профилями и материалом контроллер восстанавливает U, V, A и историю PML и задаёт соответствующий момент начала.

## Шаг, кадр и результат

`SGSolverConfig` принимает общие селекторы шага и такта, `max_steps`, `kim_beta` (по умолчанию 0), `kim_gamma` (0,5) и `check_finite_each_step` (False). При выборе `cfl_safety` выполняется глобальная оценка Ланцоша на собранных массе, жёсткости и статическом демпфировании. Формула границы шага и поля `SGSpectrumData` соответствуют [контракту tenzor, §4](LIN_ELAST_2D_TENZOR_NEWMARK_KIM_CU_EXTERNAL2.md#4-конфигурация-и-спектр). Деление шага и такта описано в [TIME_GRID2](../TIME_GRID2.md).

Предиктор даёт \(u^*=u+h v+h^2a/2\), \(v^*=v+ha\). В \(F^*\) один раз собираются упругость, динамическая сила, массовое демпфирование, ABC и вклад PML. С \(a'=M^{-1}F^*\) и \(\delta a=a'-a\) корректор записывает \(u'=u^*+\beta h^2\delta a\), \(v'=v^*+\gamma h\delta a\) и \(a'\). По запросу диагностика проверяет все строки решения и суммарной силы после каждого внутреннего шага.

Кадр принимает только VX=4 и VY=5 в N, MAIN и BOUNDARY. Каждое вхождение в DTO вносит скорость соответствующего глобального узла, умноженную на свой вес, в заданную позицию кадра. Порядок компонент, повторения и суммирование совпадающих позиций сохраняются. Неподдерживаемая компонента даёт ValueError до начала сессии, решатель остаётся в READY. Проверка конечности вычисленного кадра действует также при выключенной пошаговой диагностике.

`run(sync=True)` возвращает результат, `run(sync=False)` возвращает handle с `wait()`. Сохраняются границы тактов, очереди обработчиков, команды SAVE/COMPLETE/ABORT и `reset()`. Положительный терминальный исход по умолчанию выполняет SAVE и завершает расчёт кодом TIME_END. Действуют типы ошибок compile, mesh, prepare и run, включая причинное исключение обработчика. [SolverAPI](../SOLVER_API2.md) и [внутреннее устройство](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_CU_INTERNAL2.md).

## Декартов PML

Статическая физика `SGPhysicsTypeEnum.PML` накладывается на материал выбранных элементов MAIN. Компоненты \(d_x,d_y\) в физических осях имеют размерность \(\mathrm{с}^{-1}\). Допустимы конечные неотрицательные значения. Модель принимает пару \((d_x,d_y)\) на каждую P-позицию. В прямом `SGPhysicsData` форма массива равна `(2, P_phi)`. На пересечении носителей решатель сначала суммирует профили по направлениям, затем применяет один двумерный оператор. Это включает инерционный член \(d_xd_y u\) в углу.

При `prepare()` коэффициенты обновления истории вычисляются по суммарному профилю с фактическим внутренним шагом. Если изменить шаг или профили, повторный `prepare()` пересчитает коэффициенты и обнулит историю слоя.

Для декартова согласования задают \(d_x=d_x(x)\) и \(d_y=d_y(y)\), начиная с нуля на внутренней границе каждой полосы. Решатель проверяет значения поля, а построение направленных профилей и разрешение волн сеткой обеспечивает модель.

В модели полупространства боковые полосы доходят до свободной поверхности. Нижнюю и боковые полосы заполняют тем же материалом, что и продолжение прилегающей среды. Для ненулевого профиля задают `step_dt` или `steps_count` вместе с селектором тактов. Попытка применить `cfl_safety` к связанной системе с памятью даёт `SGPrepareError(SPECTRUM_FAILURE)`. Шаг подбирают с учётом сетки, материала и интенсивности поглощения.

Пример для сетки, в которой физическая область ограничена \(|x|\le x_0\) и \(y\ge y_0\), а внешние полосы толщины `L` уже включены в MAIN. Границы полос совпадают с гранями элементов, `d_max` задаётся в обратных секундах. Поле добавляется до `model.prepare()`.

```python
import numpy as np
from semgpu2.model import SGPhysicsModel
from semgpu2.solvers.lin_elast_2d_seismic_newmark_kim_cu import SGPhysicsTypeEnum
from semgpu2.solvers.solver_api import Float64Array

def profile(coord: Float64Array, time: float | None, node_id: int, elem_id: int | None) -> Float64Array:
    distance = np.maximum([abs(coord[0]) - x0, y0 - coord[1]], 0.)
    return d_max * (distance / L) ** 2

elements = mesh.elements_filter(1, lambda c: bool(abs(c[0]) > x0 or c[1] < y0))
model.add_physics(SGPhysicsModel.from_formula(
    "PML", int(SGPhysicsTypeEnum.PML), mesh, 1, elements, profile,
))
```

После подготовки `solver.pml_entity_ids` задаёт порядок элементов слоя. В `solver.pml_history` лежат четыре строки по локальным Q-позициям этих элементов в указанном порядке. Строки соответствуют истории \(\partial_x u_x,\partial_x u_y,\partial_y u_x,\partial_y u_y\). При новой подготовке история инициализируется нулями. При продолжении с сохранённой точки копируют `solver.pml_history[:, :]` вместе с `solver.solutions[0][:, :]` после подготовки целевого экземпляра.
