# Сейсмический p6 для четырёх независимых источников

`lin_elast_2d_seismic_newmark_kim_p64s_cu` выполняет четыре опыта плоской деформации на общей полной сетке p6/h10 в FP64. Слои 1…4 соответствуют вертикальному источнику Рикера в точках x = 100, 300, 500 и 700 м при y = 0. Их глобальные номера узлов — 270, 390, 510 и 630. Частота 30 Гц, время пика 0,05 с, амплитуда вертикальной силы −1. Координаты, нумерация верхнего ряда, задание материала и PML, произвольные N- и MAIN-приёмники и выбор шага по CFL следуют тем же правилам, что у семиопытного решателя. [Контракт сетки и физики](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_P67S_CU_EXTERNAL2.md)

```python
from semgpu2.solvers import lin_elast_2d_seismic_newmark_kim_p64s_cu as p64s

solver = p64s.SGSolver(p64s.SGSolverConfig(t_end=1., tact_dt=.001, cfl_safety=.8, kim_beta=1/27))
```

У `solutions[0]` форма `(24, N)`: шесть последовательных строк UX, UY, VX, VY, AX и AY на опыт. Узловой отклик имеет восемь строк. Список `SGReceiverComponentEnum` задаёт восемь каналов от `VX, VY` до `VX_S4, VY_S4`. Полный кадр такого приёмника читается как `frame.reshape(4, 2, frame_size)`. Команда `SAVE` сохраняет решение и историю PML формы `(16, 49 * len(pml_entity_ids))`; для продолжения оба поля копируются после подготовки экземпляра `p64s`. Число опытов задаётся при компиляции общей CUDA-реализации двух решателей. [Устройство оператора и шага](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_P67S_CU_INTERNAL2.md)

## Отражение сейсмограмм

Ось отражения проходит через x = 700 м. Источники 100, 300 и 500 м переходят в 1300, 1100 и 900 м соответственно. В зеркально-симметричной постановке для такого вертикального источника сейсмограмму в точке приёмника x получают из кадра парного опыта в точке 1400 − x при той же глубине. Горизонтальная скорость VX меняет знак, вертикальная VY сохраняет знак. Для этого преобразования нужны зеркально соответствующие геометрия, материал, PML, начальные и граничные условия и позиции приёмников. Для асимметричной среды отражённая сейсмограмма относится к зеркальной модели. Сам решатель выдаёт четыре непосредственно рассчитанных опыта.
