# Сейсмические CUDA-решатели фиксированного порядка p1–p9

Для каждого штатного `ALine(order=p)` при \(1\le p\le 9\) сборка `SEMGPU2_BUILD_CUDA=1` предоставляет отдельный модуль `semgpu2.solvers.lin_elast_2d_seismic_newmark_kim_p{p}_cu`. Число в имени равно полиномиальному порядку. В одном процессе можно использовать несколько порядков. Например, для сеток третьего и девятого порядка доступны следующие модули.

```python
from semgpu2.solvers import lin_elast_2d_seismic_newmark_kim_p3_cu
from semgpu2.solvers import lin_elast_2d_seismic_newmark_kim_p9_cu
```

Каждый модуль экспортирует `SGSolver`, `SGSolverConfig` и собственный `SOLVER_ID`. Физика, поля состояния FP64, интегрирование Ньюмарка–Кима, SAVE, синхронный и асинхронный запуск и приёмники соответствуют [контракту штатного сейсмического решателя](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_CU_EXTERNAL2.md).

## Входная сетка

`compile(n_count, pets, pq_spaces)` использует число глобальных узлов и топологию пространств. Аргумент `pets` сохраняется для совместимости с SolverAPI и игнорируется. Константы W, V и G принадлежат выбранному модулю.

Пусть \(n=p+1\). MAIN содержит два фактора с ID 0 и \(n^2\) локальных P/Q-позиций на элемент. BOUNDARY содержит один фактор с ID 0 и \(n\) позиций на грань. Решатель проверяет ранги, ширины, смещения и индексы связности при `compile()`. Сетка другого порядка отклоняется. Вызывающий код обеспечивает штатное расположение и нумерацию узлов ALine данного порядка.

Первый фактор меняется быстрее второго. Локальная позиция MAIN равна \(j=j_0+n j_1\), где \(0\le j_0,j_1<n\). На границе она равна \(j=j_0\). Например, у эталонного p5 ширины MAIN и BOUNDARY равны 36 и 6 соответственно.

Получение таблиц и устройство ядер описаны во [внутренней карточке семейства](LIN_ELAST_2D_SEISMIC_NEWMARK_KIM_P5_CU_INTERNAL2.md).
