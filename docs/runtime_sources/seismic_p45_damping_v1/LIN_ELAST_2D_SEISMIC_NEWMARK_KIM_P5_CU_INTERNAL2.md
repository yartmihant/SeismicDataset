# Сейсмические CUDA-решатели p1–p9 — внутреннее устройство

Каталог p5 содержит общие исходники специализированных ядер. CMake компилирует их для каждого порядка с отдельным пространством имён C++, solver ID и таблицами фактора из каталога выбранного порядка. Каждый модуль `_native` можно импортировать по имени соответствующего решателя. [Цели сборки](../../CMakeLists.txt), [эталонный backend](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p5_cu/backend).

## Таблицы ALine

При \(n=p+1\) объект `factor` в константной памяти CUDA содержит \(n\) весов W и по \(n^2\) значений базиса V и производных G. Матрицы записаны построчно в порядке `[q, p]`. Коллокация даёт действие V выбором узлового значения. Градиент использует G, сопряжённая дивергенция использует транспонированную G, геометрическая мера использует веса W. Статический размер фактора позволяет разворачивать одномерные свёртки при компиляции. [Таблицы p5](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p5_cu/backend/factor_tables.cuh), [свёртки](../../src/semgpu2/solvers/lin_elast_2d_seismic_newmark_kim_p5_cu/backend/operators/pet.cuh).

Таблицы получают из штатного ALine без сжатия по симметрии. Следующий код воспроизводит FP64-литералы для поля каждого из трёх массивов. Переменная `order` выбирает порядок.

```python
from semgpu2.model import SGPETALineModel

order = 5
local = SGPETALineModel("line", order=order).build_data(use_symmetry=False)
tables = (local.weights, local.values, local.grads[:, :, 0])
w, v, g = [[float(value).hex() for value in table.flat] for table in tables]
```

## Адресация

Ось x CUDA-блока задаёт локальную позицию, ось y — элемент или грань. При ширине \(w\) блок обрабатывает \(\lfloor 512/w\rfloor\) целых элементов или граней. Для MAIN ширина равна \(n^2\), для BOUNDARY — \(n\). Например, блок MAIN имеет размеры `(4, 128)` при p1, `(36, 14)` при p5 и `(100, 5)` при p9. В неполном последнем блоке все потоки проходят коллективные барьеры. Индексы глобальной связности и полей имеют тип `int64`, локальные индексы — `int`.

В сборке SM86 все 822 коэффициента p1–p9 побитно совпали с данными ALine в секциях `.nv.constant3` геометрии и отклика. Для каждого порядка регрессия сравнивает SAVE, продолжение и CFL-спектр со штатным решателем на сетке, занимающей несколько блоков MAIN. [Адресные проверки](../../tests/tests_lin_elast_2d/seismic_newmark_kim/test_reg_seismic_fixed_orders.py).
