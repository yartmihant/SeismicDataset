Глава 1.6. Повторная визуальная серия на оптимизированном p67s

Область: основная 1400×700 м, x=0…1400, y=−700…0. Исходные EFVB/ECVB700×700 растягиваются по x вдвое, скорости не масштабируются. PML350 м слева, справа и снизу; полная область x=−350…1750,y=−1050…0. Верх свободный, внешние края PML естественные свободные; ABC нет. Граничные элементы и граничное пространство не создаются.

Материал: изотропная линейная упругость, плоская деформация, плотность1000 кг/м³. Однородный контроль: Vp4087, Vs2431.62036 м/с. Двухслойный: верхний тот же, нижний Vp3963, Vs2357.84473 м/с, интерфейс y=−350. Датасет: EFVB00000, EFVB00001, ECVB12404, ECVB00065. Для ECVB используются прежние алгоритмы сглаживания слоёв / общих CAD-сплайнов с сохранением регионов; предел подгонки7.5 м относится к исходной700×700 геометрии до растяжения. Материалы боков продолжаются горизонтально, дна — вертикально; углы имеют материал соответствующего угла основной области. Растровая подмена ECVB не допускается.

Дискретизация: p6, GLL7×7 на Q2-геометрии, целевой размер10 м, верх ровно210 элементов по10 м вместе с боковыми PML. Для криволинейных сеток10 м — целевой размер, не гарантия размера каждого элемента; распределение площадей и положительность Якобиана сохраняются в geometry.json. Первые1261 глобальный узел — верх слева направо; source IDs315/420/525/630/735/840/945. Только объёмная страта MAIN1.

Источники: семь НЕЗАВИСИМЫХ решений на одной геометрии, x175/350/525/700/875/1050/1225,y0. Каждый опыт — одна точечная сила вниз Fy=−(1−2q²)exp(−q²) Н/м, q=π·30·(t−0.05). Встроенный аналитический Рикер30 Гц, t0=0.05 с, пик1 Н/м. Сила постоянна между сетками, энергия источника не калибруется. Семь волн не складываются в одном физическом поле.

PML: направленные квадратичные профили dx=173.0886108476381·(distance_x/350)² и dy=173.0886108476381·(distance_bottom/350)² с⁻¹. В углах действуют обе компоненты. Это память PML31100, а не прежний массовый демпфер. Дополнительного массового демпфирования нет. Максимум соответствует принятому уровню k0.5; толщина350 м, ABC нет.

Интегрирование: FP64, Newmark–Kim β=1/27,γ=0.5. t0…1 с, tact_dt0.001 с. dt автоматически оценивается решателем с cfl_safety0.8 отдельно для каждой геометрии, общий для её семи источников. Число внутренних шагов не фиксируется заранее. Native CFL характеризует упругую часть, не является доказательством спектральной устойчивости всей связанной PML-системы.

Артефакты: полные Vx/Vy во всех узлах каждые0.05 с (21 кадр на источник), поверхностные Vx/Vy во всех1261 GLL-узле верха каждые0.001 с (1001 отсчёт), включая боковые PML. Для физических оценок основная область выделяется отдельно. Всего6 геометрий×7 источников=42 опыта. Два масштаба визуализации: линейный ±1e−10 м/с, общий для компонент/моделей/времени, и знаковый логарифмический с общими пределами. Насыщение линейной шкалы не изменяет исходные массивы. Анимации5 кадров/с, замедление4×. Растеризация поля только для отображения, линейная внутри треугольников по GLL-узлам; значения сейсмограмм не интерполируются.

Проверки: положительный Якобиан на полной Q2-карте, конформность и топология сетки, точный верх/источники, сохранение материала, конечность каждого полученного кадра и терминального состояния/PML, побитовое совпадение поверхности и полного поля на21 общем времени, контроль времени/числа кадров, SHA массивов. Это повторная визуальная серия, не новая независимая оценка сеточной сходимости всего датасета.
