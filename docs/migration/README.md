# Перенос из TrySEMGPU

Дата: 6 ноября 2026 года. Основание — прямое поручение пользователя полностью перенести `research/seismic_dataset` в самостоятельный SeismicDataset и оформить главы 1.1/1.2 по правилам MilenSem2D.

## Состав

[file_map.json](file_map.json) содержит исходный Git HEAD TrySEMGPU, исходный status исследовательской папки, 167 файлов с прежним и новым относительным путём, размером и SHA256. Учитываются незакоммиченные пользовательские изменения, untracked CU-серия и статистика. Python-кэши исключены; исходные поля в существующем `src/` оставлены на месте.

Python-скрипты адаптированы к новым импортам и путям. Их первоначальные байты сохранены в `original/scripts/*.py.txt`; это исторические свидетельства, не исполняемые копии. Оригинальный README и ignore-файл также сохранены в `original/`. Числовые JSON, NPZ, изображения и презентация перенесены побайтно. В протоколах и отчётах обновлена навигация; содержательные ограничения сохранены.

`scripts/project_paths.resolve_provenance()` проверяет ожидаемый SHA256 и ищет подходящий текущий файл, исходный текстовый снимок или локальный native-снимок. Он не подменяет старый хеш хешем отредактированного скрипта. Исторические Windows-пути и отсутствующие старые массивы остаются частью описания опыта; их наличие не заявляется.

## Git и данные

Прежний SeismicDataset содержал один коммит `65954a5` с 120000 исходными текстовыми файлами, без remote. Для компактной новой истории прежняя `.git` сохраняется в `.local-backups/git-before-reorganization/`. Это локальная резервная копия, исключённая из нового Git. Удалять её без отдельного решения пользователя нельзя.

Новая Git-база хранит только сценарии, правила, отчёты, компактные метаданные, отобранные рисунки и презентацию. Исходные 4,6 ГБ в `src/` не удаляются. Запасная старая Git-база остаётся на диске, поэтому уменьшение активной истории не равнозначно освобождению всего занятого места.

## Проверки и границы

Mypy охватывает весь собственный Python-код. Для дневников проверяются синтаксис ячеек, nbformat, сохранение AST при цикле `.py → .ipynb → .py` и успешное выполнение только отчётных ячеек. Проверены комплекты имён исходных полей и контрольное поле каждого класса; это не новый полный пересчёт статистики.

Локальные CU-массивы №12404 проверены на формы, координаты, завершённость и доступность provenance после переноса. Математические/физические результаты не пересчитывались. CUDA/CEED runtime, полная конвертация данных, модели №65 и историческая Windows-сходимость заново не запускались. Собственная среда настроена для отчётов и подготовки данных; native-профили описаны отдельно в [ENVIRONMENT.md](../ENVIRONMENT.md).

Исходная исследовательская папка целиком сохранена в `.local-backups/research-before-reorganization/`; SHA256 всех 167 файлов сверены с картой переноса. В TrySEMGPU остался навигационный README со ссылкой сюда. Его рабочее дерево содержит удаление перенесённых материалов; коммит основного репозитория этим поручением не выполняется.
